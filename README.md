# CULTURA — Signature Edition

A premium, image-led cultural discovery website with an editorial hero, interactive 3D globe, culture explorer cards, region browsing, Indian state and union territory atlas, search, and culture detail modals.

## What's new in this redesign
- More distinctive editorial art direction with warm gold, coral and mint accents over a deep midnight canvas.
- Bigger, more dramatic headline and image-led hero composition.
- More breathing room and richer image treatments for culture cards.
- Proper two-column culture cards on phones instead of cramped desktop-like columns.
- Horizontally scrollable category filters on mobile.
- Enhanced card depth, image hover movement, atmospheric backgrounds and quote section.
- Fixed the broken image used for the Maasai communities card.
- Existing search, filters, 3D globe and cultural content remain in place.

## Run it
Extract the ZIP and open `index.html` with VS Code + Live Server, or open it in a browser. An internet connection is needed for Google Fonts, Unsplash images and the Three.js globe.

The newsletter form is a front-end demo and does not send emails.


## Travel experience prototype
- Open `travel.html` for 3D animated travel package cards and the enquiry form.
- Open `user.html` for the traveller request-status page.
- Open `admin.html` for the demo approval dashboard (username `admin`, password `cultura123`).
- Package prices are illustrative INR estimates; no live inventory or payment processing is connected.
- The prototype stores requests in browser localStorage only. It is not production authentication or a secure multi-user database. For launch, connect a backend/database, secure authentication and role-based admin access, server-side validation, and payment/booking providers as needed.
